# MPC Design System

Tokens, logos, and rules shared across MPC projects. Stack-agnostic, with no runtime
dependencies.

This folder is slated to be split into an independent repository, so it does not
reference files in the host repository. The only exception is `scripts/sync-assets.mjs`;
the reason is given under "To change the logo" below.

## 5-minute start

### Projects using CSS

```css
@import "@mpc/design/tokens.css"; /* --copper, --background, --radius-lg ... */
@import "@mpc/design/utilities.css"; /* .label-eyebrow, .hairline-t, .reveal ... */
```

```html
<div class="label-eyebrow">Investment Case</div>
<h2 style="color: var(--foreground)">…</h2>
```

### Tailwind v4

Wire the tokens into the Tailwind theme. `--color-*` is a Tailwind namespace, so map it
with aliases; `--font-*` and `--radius-*` take literal values because Tailwind uses those
names directly.

```css
@import "@mpc/design/tokens.css";

@theme inline {
  --color-copper: var(--copper);
  --color-surface: var(--surface);
  --font-display: "Space Grotesk", "Inter", sans-serif;
  --radius-lg: 6px;
}
```

### Flutter

```dart
import 'tokens.dart'; // copy dist/tokens.dart

Container(color: MpcColors.background,
  child: Text('MPC', style: TextStyle(fontFamily: MpcFonts.display,
                                      color: MpcColors.copper)));
```

### Others (Sass, design tools, scripts)

- `dist/tokens.scss` — Sass variables
- `dist/tokens.json` — flat JSON with name, value, hex, and usage
- `tokens/*.json` — DTCG source. The format read by Figma token plugins and Style Dictionary

### Projects using coding agents

```bash
cat node_modules/@mpc/design/ai/CLAUDE.md >> CLAUDE.md
```

The token list, composition rules, voice rules, and logo prohibitions are compressed into
one block. This is the path that keeps the voice consistent even when no one reads the docs.

## What's inside

| Path                | Contents                                                  |
| ------------------- | --------------------------------------------------------- |
| `tokens/`           | **Source of truth.** 43 tokens in DTCG format             |
| `content/`          | **Source of truth.** Voice, pattern, and logo rules (KO/EN) |
| `dist/`             | Generated. CSS, JSON, SCSS, Dart, utility CSS             |
| `docs/`             | Generated. 4 human-readable documents                     |
| `ai/`               | Generated. Compressed rules for agents                    |
| `assets/logo/`      | SVG 16 · PNG 48 · manifest                                |
| `css/utilities.css` | Utility layer source (hand-written CSS that consumes tokens) |

**Only three places are edited by hand: `tokens/`, `content/`, and `css/`.** Everything
else is regenerated by `npm run build`.

## Making changes

```bash
npm run build     # tokens/ + content/ → dist/ + docs/ + ai/
npm run check     # run the above and verify generated output is up to date (for CI)
```

`build` doubles as validation. It fails with exit code 1 on an unsupported `$type`, an
unparseable color, or tokens with colliding names.

### To change the logo

The artwork generator is not in this package. It needs `sharp` and `opentype.js`, which
would force Flutter and Figma consumers to install a native image toolchain as well.
To modify the mark, regenerate it in the host repository and then sync.

```bash
cd .. && bun run build:brand   # regenerate logos + copy into this package
```

## Why it is built this way

**Authored in oklch, shipped as hex.** A single copper cannot serve both paper and a
near-black interface, so values split per surface, and that judgment is only accurate in
oklch. Printers, decks, and Flutter want hex, so conversion happens at build time. The two
are not maintained separately, so they cannot drift.

**No color library.** The oklch → sRGB conversion is 60 lines in `lib/color.mjs`, and in
exchange this package has zero dependencies. A project on any stack can start by copying
a single file from `dist/`.

**Follows the DTCG format.** The converter is hand-built, but the file format is standard.
Style Dictionary's built-in color transforms do not understand oklch, so it is not used
today, but adding it later or connecting a Figma token plugin will not require a rewrite.
